# NamedChest-1.4.0 (Paper 1.18.2 — 26.2.x)

## [⭐] Нововведения и улучшения

* **Интеграция [DecentHolograms](https://github.com/DecentSoftware-eu/DecentHolograms)**: Добавлена полноценная поддержка API DecentHolograms.
* **Настройка видимости**: В `config.yml` добавлен параметр `ignore-passable-blocks`. Теперь названия хранилищ и голограммы будут отображаться сквозь проницаемые блоки (например, высокую траву и жидкости).
* **Звуковое сопровождение**: Внедрена система аудио-отклика на действия игроков. Добавлены параметры `error-sound` и `success-sound` в `config.yml` для настройки звуков успешных и ошибочных действий.
* **Блоки из Minecraft 1.21.9**: Стандартная конфигурация обновлена и теперь включает все новые блоки, появившиеся в версии 1.21.9.
* **Продвинутый контроль версий и безопасность**: Полностью переработана система проверки обновлений. Администраторы серверов теперь будут получать уведомления о выходе критических патчей. Также добавлен механизм экстренного отключения (kill-switch), позволяющий плагину автоматически деактивироваться при обнаружении разработчиком критического бага или уязвимости.

## [🛠] Исправления и корректировки

* **Унификация задержек (Cooldowns)**: Переработана логика кулдаунов. Теперь задержка стала глобальной и синхронизируется при использовании команд, бирок и наковален.
* **Исправлена работа с наковальней**: Устранены ошибки, связанные с применением цветных имен через наковальню, добавлены проверки прав (permissions), а также задержки

## [⚙️] Технические изменения

* **Глобальный рефакторинг:** Проект был полностью переписан с чистого листа. Новая кодовая база стала значительно чище, прозрачнее и удобнее для дальнейшей поддержки.
* **Миграция на Okaeri Configs:** Для управления конфигурацией теперь используется библиотека [Okaeri Configs](https://github.com/OkaeriPoland/okaeri-configs/), что обеспечивает более надежную структуру и сериализацию данных.
